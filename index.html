    🎯 설계 원칙

    시나리오 S1–S8에서 도출
    P1
    즉시 입력 가능첫 화면 = 오늘 목록 + 입력창, 탭/메뉴 없음
    P2
    연속 입력 흐름추가 후 포커스 유지, Enter로 계속
    P3
    한 손·흔들림 대응큰 입력창, 44px+ 터치 타깃
    P4
    한 번의 탭 완료토글 방식, 취소선은 자리에 남김
    P5
    무음 자동 이월압박 표시 없이 조용히 오늘 목록에
    P6
    오늘에만 집중과거·분류·반복 배제, 정보는 제목만
    P7
    빈 상태는 시작점안내 + 입력 포커스로 첫 할 일 유도

    ⚙️ 핵심 기능 & 이월 규칙

    CRUD + 자정 롤오버
    F1
    할 일 추가제목 입력 → Enter → 목록 맨 아래
    F2
    완료 토글탭 → done 토글, 취소선·자리 유지
    F3
    할 일 삭제삭제 버튼/스와이프로 제거
    F4
    목록 표시오늘 날짜를 추가 순서대로
    F5
    자동 저장모든 변경 즉시 localStorage 반영
    R1
    오늘 계산앱 열 때 로컬 타임존 기준
    R2
    미완료 이월지난 미완료 항목의 date를 오늘로
    R3
    완료는 제외done=true는 이월하지 않음
    R4
    오늘만 표시화면엔 항상 오늘 항목만
